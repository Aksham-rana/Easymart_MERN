# EasyMart React E-Commerce 🛒

EasyMart is a modern, responsive e-commerce frontend application built with React. It allows users to browse products, manage a shopping cart, control product quantities, and complete a checkout flow with an order summary.

---

## 🚀 Features

- 🔐 Authentication flow (Login & Signup)
- 🏠 Product listing fetched from API
- 📄 Product details page
- 🛒 Add to Cart / Remove from Cart
- ➕➖ Quantity management in cart
- 💰 Automatic total price calculation
- 🧾 Checkout (Buy Now) page with order summary
- 📦 Order placement confirmation
- 🔒 Protected routes for authenticated users
- 📱 Fully responsive UI

---

## 🛠️ Tech Stack

- React
- React Router DOM
- Context API
- Axios
- Formik & Yup
- CSS (Custom Styling)
- Vite

## ⚙️ Installation & Setup

1. Clone the repository  
   ```bash
   git clone https://github.com/Aksham-rana/Easymart_MERN

2. Navigate to the project folder
   ```bash
   cd easymart-react

3. Install dependencies
   ```bash
   npm install

4. Start the development server
   ```bash
   npm run dev
